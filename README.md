# Export to Word — Obsidian 插件使用说明

## 这是什么

在 Obsidian 里一键把当前笔记导出为 Word（.docx）文档，图片自动嵌入，不需要安装 Pandoc 或任何外部工具。

---

## 快速上手

### 第一次使用

1. 重启 Obsidian：按 `Cmd+P`，输入 `Reload app without saving`，回车
2. 确认插件已启用：打开 `Settings → Community plugins`，找到 **Export to Word**，确保开关是打开的

### 导出笔记

1. 打开你想导出的笔记
2. 按 `Cmd+P` 打开命令面板
3. 输入 `Export current note to Word`，回车
4. 等几秒，右上角会弹出通知「导出成功：xxx.docx（N 张图片）」
5. 文件默认保存在 **桌面**

就这三步，没了。

---

## 设置项

打开 `Settings → Export to Word`（在左侧栏最下面的"第三方插件"区域）：

| 设置 | 选项 | 说明 |
|------|------|------|
| **导出位置** | 桌面 / 下载文件夹 / 和笔记同目录 | 默认保存到桌面 |
| **图片尺寸** | 原图大小 / 限制最大宽度 | 默认原图大小，不做任何压缩 |
| **最大宽度** | 数字（像素） | 仅在选择"限制最大宽度"时出现 |
| **文档标题来源** | 文件名 / 笔记第一个标题 | 决定 Word 文件名用什么 |

## 支持的语法

| 语法 | 效果 |
|------|------|
| `# 标题` ~ `###### 标题` | Word 标题 1-6 级 |
| `**粗体**` `*斜体*` | 粗体、斜体 |
| `[链接](url)` | 超链接 |
| `` `行内代码` `` | 等宽字体 |
| ` ```代码块``` ` | 带背景的代码段 |
| `> 引用` | 左侧蓝色竖线引用块 |
| `- 列表` `1. 列表` | 无序/有序列表（支持嵌套） |
| `| 表格 |` | Word 表格 |
| `---` | 分隔线 |
| `![[图片.png]]` | 嵌入原图 |
| `![[图片.png\|320]]` | 嵌入图片，宽度限制 320px，高度等比缩放 |
| `![alt](attachments/a.png)` | 标准 Markdown 图片 |
| `[[页面链接]]` | 转为纯文本（Word 里没有 wiki link） |
| `[[页面\|显示名]]` | 转为显示名纯文本 |

## 常见问题

**Q：导出后图片没有显示？**
检查图片是否在 Obsidian 仓库内。插件通过 Obsidian 的 vault API 查找图片，仓库外的图片无法读取。

**Q：图片被压缩了？**
默认不压缩。确认 Settings → Export to Word → 图片尺寸 = "原图大小"。

**Q：导出的文件在哪？**
默认在桌面。可以在设置里改成下载文件夹或笔记同目录。

**Q：命令面板里找不到 Export 命令？**
需要先打开一篇 .md 笔记，命令才会出现。如果还没有，重启 Obsidian 试试。
